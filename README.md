# Giovanni Cetrangolo — Developer Portfolio

## About
Personal portfolio website showing my skills, projects, and experience as a Fullstack Web Developer.
This portfolio presents my web development skills, personal projects, and freelance experience.

## Technologies

- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** PHP, Laravel
- **Databases:** MySQL, MongoDB
- **Tools:** Git, GitHub, Docker

## Features

- Responsive layout for desktop and mobile devices
- Navigation menu
- About section and technical skills
- Portfolio section showing web development projects
- Contact form interface
- Links to GitHub repositories and professional profiles

## Getting Started

To run the project locally:

1. Clone the repository:

   git clone https://github.com/GiovanniCetrangolo/portfolio.git

2. Open the project folder.
3. Open `index.html` in your browser.

No additional dependencies or build tools are required.
